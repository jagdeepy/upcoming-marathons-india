# Upcoming Marathons India

Public calendar: https://jagdeepy.github.io/upcoming-marathons-india/

## Add or update an event

1. Open the events.json file in this repository: https://github.com/jagdeepy/upcoming-marathons-india/blob/main/events.json
2. Select the pencil button to edit it.
3. Replace the contents with a JSON list like this, filling in the event details:

    [
      {
        "name": "Event name",
        "date": "2027-02-14",
        "location": "City, India",
        "distance": "10K / Half / Full",
        "details": "Registration link or extra details"
      }
    ]

4. Choose Commit changes. The event will appear on the public calendar after GitHub updates the site.

Use date format YYYY-MM-DD. To add more events, put a comma between event blocks. Remove an event block to take it off the calendar.
